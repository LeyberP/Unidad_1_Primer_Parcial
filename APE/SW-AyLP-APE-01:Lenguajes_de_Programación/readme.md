## Descripción del Proyecto

Este proyecto consiste en una consulta científica y el desarrollo de un informe técnico estructurado que permite:
* **Analizar la evolución histórica** de los lenguajes desde la década de 1940 (código máquina) hasta la actualidad.
* **Establecer la relación directa** entre lenguajes antecesores históricos (FORTRAN, COBOL, ALGOL, C) y las tecnologías modernas.
* **Comparar técnicamente** lenguajes contemporáneos (**Python, Java, JavaScript, C++, Go y Rust**) bajo criterios de tipado, paradigmas y ejecución.
* **Sintetizar información compleja** mediante una infografía técnica que actúa como matriz de decisión para proyectos de software.
* **Validar fortalezas operativas** como la seguridad de memoria en Rust, la concurrencia en Go o el desarrollo ágil en Python.

Todo el informe técnico está construido aplicando el formato de Guías APE institucional y respaldado por referencias bibliográficas bajo el estándar internacional IEEE.
