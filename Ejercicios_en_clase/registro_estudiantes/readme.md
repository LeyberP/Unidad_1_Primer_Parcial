DESCRIPCION
Este código en Java es un programa interactivo que solicita datos al usuario nombre, edad y tres notas, procesa la información calculando el promedio de las tres notas.
Convierte la edad ingresada a diferentes formatos: decimal, binario y hexadecimal.
Muestra resultados en pantalla: imprime el nombre, la edad en sus tres representaciones y el promedio de las notas.
En resumen, es un programa sencillo de entrada/salida que combina manejo de datos personales con operaciones matemáticas y conversiones numéricas.
